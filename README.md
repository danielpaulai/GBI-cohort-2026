## ⚡ One-line install

Open Terminal (Mac/Linux) or PowerShell (Windows) · paste this · hit enter:

```bash
curl -fsSL https://raw.githubusercontent.com/danielpaulai/GBI-cohort-2026/main/install.sh | bash
```

Done in 60 seconds.

## 🔧 Troubleshooting

### "claude command not found"
→ Install Claude Code Desktop first: `https://claude.ai/download`

### "Permission denied"
→ Run with explicit bash: `bash <(curl -fsSL [URL])`

### "Skill didn't trigger"
→ Restart Claude Code · or run: `claude skills reload`

### Anything else
→ WhatsApp Karthik (cohort tech support) · response in under 4 hours
