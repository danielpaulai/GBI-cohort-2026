# Getting Started · 10X With AI Cohort

> **You just installed.** Now what?

---

## ✅ STEP 1 · Verify the install worked

Open Claude Code Desktop. Open a new chat. Type:

```
List my installed skills
```

You should see (at minimum):
- `ikigai-discovery-journey`
- `voice-profile-builder`
- `business-brain-builder`

If you don't · run the install again:

```bash
curl -fsSL https://raw.githubusercontent.com/danielpaulai/GBI-cohort-2026/main/install.sh | bash
```

---

## 🌸 STEP 2 · Run your Ikigai Discovery (10 min)

In Claude Code · type:

```
Let's do my Ikigai
```

Claude will walk you through 16 questions:
- 4 about what you LOVE
- 4 about what you're GOOD AT
- 4 about what the WORLD NEEDS
- 4 about what you can be PAID FOR

At the end · Claude generates:
- Your **Ikigai sentence** (1-line purpose)
- 3 **monetization paths**
- 3 **next steps** (today · this week · this month)
- 3 **AI Employee picks** for your cohort journey
- A **stunning HTML page** to print and share

Time: ~10 min.

---

## 🎤 STEP 3 · Run your Voice Profile (Day 2 prep · 15 min)

After Ikigai · type:

```
Build my voice profile
```

You'll provide:
- Your LinkedIn URL (or paste 5-10 posts)
- Then answer 16 calibration questions

Output: a `voice-dna.md` file Claude will use for every Employee.

---

## 🧠 STEP 4 · Build your Business Brain (Day 2 PM · 45 min)

Type:

```
Build my business brain
```

Claude walks you through 15 sections · auto-pulling from your Ikigai + Voice Profile so you don't re-answer. Total time: ~45 min.

Output: a complete `BUSINESS-BRAIN.md` pinned to all 5 Claude Projects.
